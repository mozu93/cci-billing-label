CCI請求書・ラベル発行システム
使い方マニュアル

対象バージョン: v2.5.4 ／ 最終更新: 2026年9月

このマニュアルについて

  • 商工会議所向けの請求書・領収書・宛名ラベル発行アプリの操作ガイドです。
  • 各機能はウィンドウ左側のメニューで切り替えます。ウィンドウ幅が狭いとメニューはアイコンだけに畳まれます（左上の ≡ ボタンで手動切替も可能）。
  • 「年度」は4月〜翌3月です（例：2027年2月は2026年度）。各画面の年度は当年度を初期表示します。
  • 請求書・領収書の番号は、2027年3月までは「INV-年月-月ごとの連番」（例：INV-202703-0012）、2027年4月以降は「INV-年度-年度内の通し番号」（例：INV-2027-0001、毎年4月に1から）です。領収書は「RCP-」で始まる別の連番です。
  • どの画面でも、所属・役職は氏名（代表者名）の左に並びます（宛名の「所属・役職　氏名」の順）。
  • プルダウン・数値欄・日付欄は、マウスホイールでは値が変わりません（画面をスクロールするつもりで値が変わる誤入力を防ぐため）。値はクリックやキー入力、▲▼ボタンで変更してください。
  • 設定・データベース・ログは、ユーザーフォルダ内の .cci-billing-label フォルダに自動保存されます（バックアップ推奨）。PDFとバックアップは cci-billing-label フォルダに保存されます。

概要

このアプリは、商工会議所が会員向けに発行する請求書・領収書・宛名ラベルをまとめて管理・印刷できるシステムです。

メニュー項目主な用途
単発発行1件単位で請求書・領収書を手入力して発行
まとめて発行案件（プロジェクト）単位で名簿を管理し、請求書・領収書を一括発行
入金管理単発発行・まとめて発行の請求書をまとめて確認し、入金を記録
宛名ラベル発行会員リストから宛名ラベル・名札を印刷
修正・再発行発行済み書類の内容修正・PDF再出力
登録・マスタスタッフ・業務名・請求テンプレート・会員情報の管理
設定発行元情報・メール・バックアップ・操作ログ

インストール・起動

初回インストール

  1. GitHub のリリースページから CCIBillingLabel_Setup_x.x.x.exe をダウンロードします。
  2. ダウンロードしたファイルをダブルクリックして実行します。
  3. 画面の指示に従ってインストールを完了します（管理者権限は不要です）。
  4. デスクトップまたはスタートメニューの「CCI請求書・ラベル発行システム」を起動します。
インストール先はデフォルトで %LOCALAPPDATA%\CCIBillingLabel になります。変更は不要です。

起動時の動作

  • 社内専用システムのためログイン画面は表示されず、そのままメイン画面が開きます。
  • 初回だけパスワードなしで担当者を選択します。選択内容は端末に保存され、次回から直接起動します。
  • 担当者を変更する場合は「ファイル」→「担当者を変更...」を選択します。
  • 起動直後に自動バックアップが実行されます（ステータスバーに完了メッセージが表示されます）。
  • 新しいバージョンがある場合、画面上部に黄色い通知バーが表示されます（バージョンアップ参照）。

単発発行

1件ずつ手入力して請求書または領収書を発行します。宛先や金額が毎回異なる場合に使います。

請求書の発行

  1. 左メニューの「単発発行」→ 画面上部の「請求書」を開きます。
  2. 「宛先」欄に宛先を入力します。会員番号を入力すると候補が表示され、選ぶと会員マスタの内容（事業所名・氏名・住所など）が入ります。候補はマウスのほか、↓キーとEnterでも選べます。
  3. 「発行設定」欄で発行方法（印刷／メール送付）・発行元・銀行口座・印鑑を選びます。
  4. 「発行項目」に請求する項目を入力します。
  5. 画面下の「支払期日」と「合計」を確認し、「発行する」をクリックします。
  6. 印刷の場合は保存先を選ぶとPDFが開きます。メール送付の場合は、送信前の確認画面で請求書PDFと実データ差し込み後の本文をプレビューし、宛先・CC・BCC・タグ付き件名・本文を必要に応じて編集して送信します。テンプレート編集欄と本文プレビューは左右2列で表示され、編集内容はプレビューへリアルタイムに反映されます。差し込みタグは一覧からダブルクリックで挿入できます。修正した件名・本文は「件名・本文をテンプレート保存」で次回以降の標準文面にできます。
請求書PDFでは、明細表の直下に「合計（税込）」、その下に税率別の対象小計と税額（「うち10%税額」「うち8%税額」）を表示します。税額の1円未満は税率ごとに切り捨てます。合計欄の罫線は明細表の「単位」「単価」「金額」列に揃えて表示されます。

画面下のボタン

発行後の動き

  • 発行後も入力内容はそのまま残ります。続けて似た書類を作るときに便利です。画面下に「INV-… を発行しました」と表示されます。
  • 何も変えずにもう一度「発行する」を押すと、「同じ内容でもう1枚発行しますか？」と確認が出ます。
  • メール送付で、送信確認画面をキャンセルした・送信に失敗した場合は、「同じ番号のまま印刷に切り替えますか？」と確認が出ます。切り替えると、同じ番号の書類を印刷用PDFとして保存できます。
  • すべての行が数量0のときは発行できません。合計が0円のときは、発行前に確認が出ます。
印刷の保存先を選ばなかった、メールも送らず印刷にも切り替えなかったなど、何も出力されなかった発行は自動で取り消されます。取り消した番号は欠番になり、操作ログに「発行取消」が残ります。入力内容は残っているので、そのまま発行し直せます。なお「修正・再発行」では、保存しなくても元の書類は取り消されません（再発行画面から出力できます）。

領収書の発行

  1. 左メニューの「単発発行」→ 画面上部の「領収書」を開きます。
  2. 宛先・発行設定・発行項目を入力します（請求書と同じ画面です。住所・支払期日はありません）。
  3. 「発行する」をクリックします。「プレビュー」「テスト送信」「すべてクリア」も請求書と同じように使えます。
領収書PDFの「内　訳」欄には、税率ごとに「10%対象」「うち10%税額」（8%の場合は「8%対象」「うち8%税額」）を表示します。税額は請求書と同じく税率ごとに切り捨てます。非課税・不課税の項目は「課税対象外」としてまとめて表示します。
メール送付では、受領者向けの原本だけをA6横のPDFとして添付します。窓口手渡し・保存・印刷では、従来どおり原本と控えをA5縦の1ページへ出力します。

まとめて発行

案件（プロジェクト）単位で会員を一括管理し、請求書・領収書をまとめて発行します。年会費・講座料など同じ案件で複数名に発行する場合に使います。

① 名簿・請求内容

  1. 左メニューの「まとめて発行」→ 画面上部の「名簿・請求内容」を開きます。
  2. 「＋ 名簿・請求内容を作成」で年度・業務名・件名・発行元・請求項目を設定します。
  3. 「保存して名簿を取り込む」をクリックします。続けて名簿取り込み画面が開きます。
  4. Excelから貼り付けるか、「Excelファイルを選択」で名簿を読み込みます。
  5. 見出し行は自動判定されます。プレビューと列の割り当てを確認して「取り込み実行」をクリックします。
名簿・請求内容は年度ごとに新しく作成します。一覧は画面上部の「年度」で切り替え、当年度を初期表示します。請求項目テンプレート（登録・マスタ）は年度をまたいで残るので、新しい名簿でも同じ項目を選べます。下の名簿は、見出しの行の「Excel出力」で、表示中の行（検索で絞り込んでいればその行）を全項目でExcelに保存できます。
v2.5.2 で「完了」「完了を戻す」「年度更新」は廃止しました。名簿は状態に関係なく、年度で絞り込んで表示します。以前「完了」にした名簿も、そのまま表示されます。
名簿の「NO.」は会員番号とは別の任意番号です。Excelの見出しが「NO.」「No.」「NO」「№」の場合は自動認識されます。
「参加者名①」「フリガナ①」「事業所所在地：郵便番号」「事業所所在地：市区町村番地」「事業所所在地：マンション・ビル名」「事業所電話番号」も自動で割り当てられます。
名簿の上部にある検索欄では、事業所名・フリガナ・氏名・氏名フリガナで該当行を絞り込めます。案件一覧との境界は上下にドラッグでき、名簿の表示高さを調整できます。

あとから名簿に追加する（キャンセル・追加申込）

一度取り込んだ名簿にも、あとから行を追加できます。既存の行は削除されません。

  1. 上の「ダッシュボード（発行・入金の状況）」から件名を選び、下の「名簿：（業務名　件名）」の「Excel・貼付で追加」をクリックします。
  2. 画面上部に「現在の名簿：〇件」と表示されます。追加分だけを貼り付けるか、Excelファイルを選択します。
  3. プレビューの「取込」列で、行ごとに「追加」「重複（スキップ）」を確認します。
  4. 「名簿に追加する」をクリックし、確認画面で内容を確認して実行します。
すでに名簿にある行（会員番号が同じ、または事業所名＋氏名が同じ）は、既定では取り込みません。名簿全体を貼り付け直しても、増えた分だけが追加されます。
同じ事業所をあえて2行登録したい場合は、「すでに名簿にある行は取り込まない」のチェックを外してください。
1件だけ追加するときは「1件追加」が使えます。既存の名簿に追加されます。チェックした行には「編集」「参加キャンセル」「キャンセル解除」「削除」が使えます（ボタンにマウスを載せると説明が表示されます）。
請求書・領収書を発行済みの行は、名簿から削除できません。参加をやめた場合は「参加キャンセル」を使ってください。発行済みの書類は履歴として残り、今後の発行と入金管理の対象から外れます。

② 請求書を発行

  1. 画面上部の「請求書を発行」を開き、年度（当年度を初期表示）・業務区分・件名で名簿を選択します。
  2. 「発行の設定」の要約で、発行元・口座・印鑑・PDF出力などを確認します。変えるときは「▼ 変更」を押して編集します（「▲ 閉じる」で要約に戻ります）。発行元・口座・印鑑の変更は案件設定へ保存され、同じDBを使う他ユーザーにも反映されます。
  3. 発行する事業所にチェックを入れます。一覧のすぐ上の検索欄で、事業所名・代表者名で絞り込めます。
  4. 名簿ごとの単価・数量を変更すると、変更内容は共有DBへ自動保存されます。数量はExcelで入力することもできます（「Excel出力」→ Excelで入力 →「Excel取込」）。
  5. 発行前に確認する場合は、1行だけチェックして画面下の「チェックした請求書をプレビュー」をクリックします。プレビューでは採番・発行済み変更・メール送信は行われません。
  6. 「チェックした請求書を発行する」をクリックすると、確認画面が開きます。発行する件数を確かめ、発行方法（印刷／メール送付）と支払期日を選んで「発行する」をクリックします。支払期日の初期値は、その名簿で前回使った支払期日（初めてなら翌月末）です。「キャンセル」なら何も発行しません。
  7. 印刷の場合は保存先フォルダを選択します。メール送付の場合は、1件目を見本に送信確認画面が1回だけ開きます。ここで直した件名・本文は、差し込みタグ（宛名・金額など）を1件ずつ置き換えて全件に使われ、CC・BCC は全件に付きます。「◯件に送信します」の確認のあと、進み具合を表示しながら続けて送信します（「送信を中止」で止められます）。メールアドレスがない事業所、中止・失敗で送らなかった分は「準備中」に戻り、番号はそのまま次の発行で使われます。

PDFファイル名

選択した項目は「_」で連結され、設定は次回以降も保持されます。

12_〇〇商事_20260730_INV-202607-0001_請求金額11,000円.pdf（2027年4月以降は管理番号が INV-2027-0001 の形になります）

メール送信設定が完了している場合、発行時に1件ずつM365メール送信の確認画面が表示されます。タグ付き文面と実データのプレビューを確認し、「送信する」または「キャンセル」を選択できます。
請求書の発行元情報が長い場合は、折り返しを防ぐため該当する行の文字サイズが自動的に縮小されます。

③ 領収書を発行

  1. 画面上部の「領収書を発行」を開き、名簿を選択します。
  2. 「発行の設定」で発行元・印鑑などを確認します（請求書と同じく「▼ 変更」で編集）。
  3. 入金済みのメンバーにチェックを入れて「チェックした領収書を発行する」をクリックし、確認画面で発行方法と発行日（初期値は今日）を選んで「発行する」をクリックします。
発行方法がメール送付の場合、添付PDFは領収書原本のみです。保存・印刷の場合は原本と控えを出力します。

入金管理

  1. 左メニューの「入金管理」を開きます。
  2. 「年度」「名簿」「種別」「状態」で表示する書類を絞り込みます。年度は当年度を初期表示し、「すべての年度」も選べます。
  3. 入金があったメンバーの行を選択し、「入金記録」ボタンで入金日・金額を登録します。
  4. 状態が「入金済み」に変わります。領収書が発行できるようになります。
書類の年度は、まとめて発行の書類は名簿の年度、単発発行の書類は発行日（4月〜翌3月）で決まります。
当年度で表示しているときに前年度以前の未入金が残っていると、「前年度以前に未入金 N件があります」と表示されます。年度を「すべての年度」にすると確認できます。

宛名ラベル発行

案件の会員リストから宛名ラベルや名札を印刷します。市販のラベル用紙（A-ONE 28185・28187・51002）に対応しています。

件名案件を選択するとメンバー一覧が表示されます。

メール送信設定

請求書・領収書・督促メールの送信と発行通知の設定です。Microsoft 365（Graph API）を使用します。

Microsoft 365 メール送信（Graph API）

項目説明
アプリケーション（クライアント）IDMicrosoft Entra ID のアプリ登録で取得
ディレクトリ（テナント）ID組織のテナント ID
送信アカウント「サインイン／確認」で実際に送信するMicrosoft 365アカウントを選択
代理送信元別の共有メールボックス等から送信する場合に、そのメールアドレスを入力。本人から送信する場合は空欄
テスト送信先受信可能なメールアドレスを入力し、「テストメール送信」で設定を確認。入力内容は保存され、次回起動時にも復元されます。単発発行の「テスト送信」の既定の送信先にもなります
テスト送信モードチェックすると、アプリが送るすべてのメール（請求書・領収書・督促・発行通知など）がテスト送信先だけに届きます。CC・BCC には送らず、件名に【テスト送信モード】、本文の先頭に本来の宛先が入ります。オンの間は画面下に赤い表示が出ます。テスト送信先が空のときはオンにできません
テスト送信モードで送ったメールも、書類の記録上は「送信済み」になります。本番のデータでは使わないでください。また、設定ファイル（config.json）を他の端末へコピーする場合は、テスト送信モードをオフにしてからコピーしてください。
Microsoft Entra ID でアプリ登録（Public Client）と Mail.Send 権限が必要です。IDを入力後、「サインイン／確認」を実行してください。代理送信元を入力した場合のみ Mail.Send.Shared も要求されます。OAuthトークンはWindowsの暗号化機能を使って保存されます。旧版の平文キャッシュは移行時に削除されるため、更新後の初回のみ再サインインが必要です。詳しくは「サーバー設定マニュアル」を参照してください。
代理送信には委任された Mail.Send.Shared 権限に加え、Microsoft 365側で代理送信元メールボックスに対する「差出人として送信」または「代理人として送信」の権限付与が必要です。権限追加後は、再度「サインイン／確認」を実行してください。
送信後の配信結果を確認するには、Entra IDアプリにMicrosoft Graphのアプリケーション権限 ExchangeMessageTrace.Read.All を追加して管理者同意を与え、「追跡用クライアントシークレット」に作成したシークレットの値を入力してください（シークレットIDではありません）。「再発行」画面の「配信状況を更新」で、配信済み・確認待ち・配信失敗と失敗理由を確認できます。
送信直後は「確認待ち」となる場合があります。数分後に再度更新してください。上段の送信受付成功は、相手先への配信完了を意味しません。
Graph APIの制限を考慮し、添付PDFは2.5MB未満にしてください。一時的な送信制限（HTTP 429）は待機後に自動再試行します。
メールの「会社名」タグには、対象書類の発行元設定が反映されます。案件または発行時に発行元を変更した場合も、その発行元名に置き換わります。

バージョンアップ

新しいバージョンがリリースされると、アプリ起動時に画面上部に黄色い通知バーが表示されます。

  1. 通知バーの「ダウンロード」ボタンをクリックします。対象バージョンのインストーラーが自動的にダウンロードされます。
  2. ダウンロードが完了すると「今すぐ更新して再起動」ボタンが表示されます。
  3. ボタンをクリックするとインストーラーが起動し、アプリが自動的に終了します。
  4. インストーラーの指示に従って更新を完了します。
ダウンロードしたインストーラーは、GitHub Releasesが提供するSHA-256と自動照合されます。一致しないファイルは実行されません。
更新中にデータが失われることはありません。ただし、念のため更新前にバックアップを取ることをお勧めします。
