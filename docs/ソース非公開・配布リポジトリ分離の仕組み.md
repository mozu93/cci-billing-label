# ソース非公開・配布リポジトリ分離の仕組み

ソースコードは `mozu93/cci-billing-label` を **Private** にし、利用者向けの
インストーラーだけは `mozu93/cci-billing-label-releases` を **Public** にして配布する。

## 初回のGitHub設定

1. `mozu93/cci-billing-label-releases` を空の **Public** リポジトリとして作成する。
2. ソースリポジトリ `mozu93/cci-billing-label` の Visibility を **Private** に変更する。
3. GitHub の Fine-grained personal access token を作成する。
   - Resource owner: `mozu93`
   - Repository access: `cci-billing-label-releases` のみ
   - Repository permissions: **Contents: Read and write**
4. ソースリポジトリの Actions secret に `RELEASES_REPO_TOKEN` として登録する。

## リリース手順

`app/version.py` のバージョンと一致する `vX.Y.Z` タグをソースリポジトリへpushする。
GitHub Actions がテスト・ビルド後、公開配布リポジトリへインストーラーと
`checksums.txt` を添付したReleaseを作成する。アプリ内の更新確認も公開配布リポジトリを参照する。

## 既存ユーザーの移行

既存の v2.2.7 以前は、旧 `cci-billing-label` リポジトリを更新確認先としている。
そのため v2.3.0 のタグだけは旧配布先にも同じインストーラーをReleaseし、既存ユーザーへ更新通知を届ける。v2.3.0 へ更新済みのアプリは新しい公開配布リポジトリを参照する。
